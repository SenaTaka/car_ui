読み: DL はあるのに払う理由が無い。差別化の核(実測 RPM のエンジン音)を全部無料で出し、Pro には「CSV・記録保存」という使用頻度の低い特典しか無い。ペイウォールは価値を体感する前(接続 3 秒後)に出ている。

## 2. 「サブスクされる」ための設計原則

1. **払う理由は毎回のドライブにある**: 音(全プリセット+追加音)と計器(ダッシュボード)は乗るたびに使う。CSV は月 1 回。前者を Pro にする。
2. **溜まるものを作る**: ドライブ履歴(セッション自動保存・振り返り)。解約すると閲覧できなくなる=継続理由。
3. **見せるのは価値の直後**: 初回の実接続で RPM が動き、自分の車でエンジン音が鳴った後。アダプタ未所有(デモモードのみ)の人には出さない(削除率 56% の主因に課金訴求を重ねない)。
4. **トライアルで「自分の車で鳴る」を先に渡す**: 年額に 7 日無料。OBD はアダプタ到着まで時間差があるので、トライアル開始は実接続後に案内する。
5. **買い切り派の逃げ道を残す**: Lifetime を年額の約 2 倍で併置(サブスク反発層=Car Scanner 比較層の受け皿、かつ年額を安く見せるアンカー)。
6. **既存ユーザーを裏切らない**: 既存 Pro/広告除去の購入者は永久にそのまま。更新前からの無料利用者はエンジン音を全部使えたまま(grandfather)。

# 自由に作れるダッシュボード(2026-09-20 追加。調査 `doc/dashboard_ui_research.md`、監査は designer 2026-09-20)

## 10. 結論
- **作る操作そのものは無料で開放する**。競合(Car Scanner・OBDLink)は自由配置+サイズ+色を無料で出しており、ここを課金の壁にすると比較で負ける。自由配置型(★4.8 / 3.3 万件)とプリセット型(★4.2 / 2,100 件)の評価差が根拠。
- **Pro は「もっと」に置く**: 複数ページ、ウィジェット無制限、テーマ、しきい値カスタムと点滅・シフトライト、横向き専用レイアウト。
- ゲーム UI から移植するのは 5 つ: 進行型シフトライト / レッドライン点滅 / アーク型 RPM / しきい値の色帯 / テーマ切替。生パラメータは見せず「種類+強弱」に畳む。

## 11. 無料 / Pro の線引き(§3 の表を上書き)

| 項目 | 無料 | Pro |
|---|---|---|
| ページ | 1 | 複数(横スワイプ、ドット表示) |
| ウィジェット枚数 | 6 枚まで(現行実装の 4 を 6 に緩和) | 無制限 |
| 種類 | デジタル / アナログ / チャート / 地図 すべて | 同じ |
| サイズ | 小 1×1 / 横長 2×1 / 大 2×2 | 同じ |
| 並べ替え・サイズ変更 | ダッシュボード上で長押し → 直接操作 | 同じ |
| スタイル | 標準(数字・針) | +アーク / バー / リング |
| テーマ | 標準 | +ナイト(黒地に琥珀)/ レース(シフトライト・アーク)/ クラシック(白文字盤) |
| しきい値 | 既定値で色が変わる(水温・油温・回転数) | 値の編集、点滅、シフトライト |
| 横向き | 縦グリッドが伸びるだけ | 横向き専用レイアウト |
| 未接続時の編集 | デモ値で編集できる | 同じ |

## 12. 直すこと(監査から)
1. プリセット適用の前に確認(手組みがある場合だけ標準アラート)。
2. アナログメーターにも鮮度(stale)表現。
3. 色を状態に結びつける: 水温・油温・回転数は既定しきい値で標準→黄→赤。それ以外の PID は色を固定しない(現在の「水温=赤」のような分類色をやめる)。
4. 編集入口の発見性: 初回の実接続成功時に 1 回だけ「長押しで並べ替え」の吹き出し。
5. 「複数レイアウト」を 1.1.0 で謳わない(未実装)。ストア文言・ペイウォールは「ウィジェット無制限」まで。複数ページは 1.2.0 で入れてから訴求する。

## 13. データモデル(1.2.0)
```
DashboardPage { id, name, widgets: [DashboardWidget] }
DashboardWidget { id, kind, pid, size: .small/.wide/.large, style: .standard/.arc/.bar/.ring }
DashboardTheme: .standard / .night / .race / .classic(色・既定スタイル・シフトライト有無を束ねる)
Threshold(PID ごと、VehicleProfile 内): warn, danger(既定値は PIDCatalog、Pro で編集)
```
既存の保存データ(widgets 配列)は 1 ページ目に移行。size/style は既定値で補う。
